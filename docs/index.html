NerdMiner V2 FX1 RC / Beta

V1.8.3-FX1 RC1

An unofficial open-source NerdMiner V2 fork advancing performance, correctness, stability, pool support and usability. Physically tested on the ESP32_2432S028_2USB (classic ESP32, 4 MB flash). Other variants are not validated.

Up to ~446 kH/s measured on our test unit, compared with ~340 kH/s on stock firmware. Results vary by board and setup.

Update to FX1 — keep my configuration

Recommended for the supported board with a compatible existing partition layout. This writes only the application at 0x10000; it does not include NVS, SPIFFS, bootloader or partition-table files.

  1. Connect your NerdMiner to this computer with a data-capable USB cable.
  2. Click the button, choose its serial device, then choose Install.
  3. When asked “Erase device?”, leave the box unchecked and click Next. Erasing would delete your settings.
  4. Keep USB connected until flashing finishes. The miner will reboot.

Do not select “Erase device”. The recommended update preserves existing Wi-Fi, mining address and pool settings only on a compatible layout. Back up the device first if the existing layout is uncertain. This is RC/Beta firmware.

Browser flashing needs a desktop browser with Web Serial, such as current Chrome or Edge. See the manual flashing guide. Open the published HTTPS GitHub Pages site to enable browser flashing. See the manual guide.
Advanced: fresh install / recovery

Settings can be lost. The factory image starts at 0x0000 and spans the NVS/configuration region. Use it only for a deliberate clean install or recovery—not to update a configured miner.

Use desktop Chrome or Edge with Web Serial, or follow the manual guide. Use the published HTTPS GitHub Pages site or the manual guide.

What FX1 improves

  • Higher physically measured mining throughput
  • Bitcoin hashing and share correctness fixes
  • Independent SHA-256d candidate validation
  • More robust job, nonce and hashrate accounting
  • HeliosPool dashboard and secure API/TLS integration
  • Pool statistics without large periodic mining slowdowns
  • Multi-pool statistics architecture
  • Memory, display and stability fixes
